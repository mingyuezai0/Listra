# 听雨（Listra）

一个本地无损音视频播放器。整个程序就是**一个网页文件**，双击用浏览器打开就能用，不联网、不装依赖、不上传任何东西。

> **Listra** = listen + rain。名字取自「听雨」的意象：窗外下雨，屋里放一张唱片。

## 开源

本项目已在 GitHub 开源（**MIT 协议**）：

- 仓库：**https://github.com/mingyuezai0/Listra**

欢迎 Star / Issue / PR。

## 快速开始

1. 双击打开 `index.html`——先出现**开屏页**（斜雨标记 + 名称，白底，短暂停留后自动淡出）。
2. 点右上角 **添加文件**，它是两选一：**选文件**（挑几个音频/视频）或**选文件夹**（整个目录扫一遍）。也可以直接把文件**拖进窗口**。
3. 导进来的东西按音频 / 视频分开放在左侧「资料库」里。点一下就开始放。

**第一次导入会弹一句说明**：软件会把文件**复制一份**存进自己这儿，你原来的文件不会被改动、也不会被删除。不想留副本可以在「设置 · 导入方式」里换成「只建索引」。

## 它是什么，不是什么

- **是**：一个把「本地音乐 + 本地视频」放在一起管、并且**绝不动原件**的播放器。文件原样存进浏览器数据库，音质画质一个字节都不改，播放走的是浏览器原生解码。
- **不是**：不是流媒体客户端，不联网、不抓取、不下载；不是音乐库管理器，不改标签、不重命名磁盘上的文件、不扫描全盘。
- 编辑详情里的名称 / 作者 / 标签是**软件内部的覆盖字段**，只写在软件里，磁盘上的文件一个字节都不动。

## 功能一览

### 资料库

- **音频 / 视频分开**两页，各显示「N 项 · 总时长」；时长还没探到的会老实写明「N 项时长未知」，不假装是 0。
- **无损标记**：flac / wav / aiff / ape / wv / dsf / dff / alac 会打上「无损」角标。
- **筛选**：按**作者**、**标签**两个筛子（只统计你自己填过的值，不会被文件里的原始标签污染）。**搜索**跨全部条目，匹配标题、作者、标签和文件名。
- **两种排列**：书架（卡片）/ 列表，随时切换。
- **重复检测**：导入时先用「名字 + 大小」预筛，沾边的才去比时长。「覆盖」会保留原来那条记录上的标记点、片段、看到哪儿、以及在收藏夹和待播里的位置，只把文件本体换掉。
- 卡片上的 `⋯` 里可以**编辑详情**（名称 / 作者 / 标签）、看**详情**（在哪些收藏夹和待播里、播放次数、累计时长）、或从资料库移除。

### 播放台

- **进度条就是波形**（canvas 画的 720 个采样桶），已播部分薄荷绿、未播浅灰绿，播放头是个圆点。
- **速度**七档：0.5× / 0.75× / 1× / 1.25× / 1.5× / 2× / 3×。
- **顺序 / 循环 / 次数**：顺序或随机；关闭、单曲、列表；单曲和列表各能再定重复几遍。
- **定时**：15 / 30 / 60 分钟后暂停，或者指定一个**具体时刻**停。
- **定量**：放完 1 / 3 / 5 / 10 首就停在那儿，等你按播放。
- **标记点**：随时记下当前位置，命名、跳转、删除。
- **片段循环**：设 A 和 B 圈出一段，打上勾的片段按 A→B 依次循环，最后一段接回第一段。
- 音量滑杆竖排，有 0 / 25 / 50 / 75 / 100 五个**卡位**，快速一甩会直接跳到下一档。

### 视频

- **播放轴上划一下就能预览那一帧**：鼠标移上去（手机是手指按上去）就在该位置上方浮出画面缩略图和时间。
- **逐帧退 / 进**两颗按钮，在时间读数左边。
- **封面用画面本身**：没有内嵌封面就取第一帧；播放过之后，封面换成退出视频时那一帧。
- **全屏**键在画面右下角。手机上全屏自动转横屏、带左右安全区、**长按 420ms 就是 2× 快进**（松手恢复当前倍速），还有一颗**防误触锁**。电脑上**点一下画面就是播放 / 暂停**。
- **悬浮小窗**：全屏键左边那颗。画面缩进一个小窗浮在屏幕最上方，**能拖**，**拖四边能改大小**；手机端还能先退回桌面，小窗照样放着。电脑端用的是浏览器原生的画中画，安卓端是系统级画中画。
- **进度保存**：视频和一小时以上的长录音会记住上次停在哪，「接着上次看」有三档——自动跳转 / 点击跳转 / 静默跳转。

### 音频

- 播放时自动打开**唱片页**：一张会转的唱片（中间放封面），点一下翻到**台词页**。
- **台词**优先读文件里的内嵌歌词（ID3 的 `USLT`、FLAC 的 `LYRICS` / `UNSYNCEDLYRICS`、MP4 的 `©lyr`）；没有的话可以**自己贴一段**，也能改掉内嵌的那份。用户贴的存成覆盖字段，不会写回文件标签。
- 电脑端（窗口宽于 860px）不翻面——**唱片和台词并排站着**，两面同时看得见。
- 唱片转 / 停是按播放状态走的，暂停再播不会把相位弹回原点。

### 收藏夹、待播与个人主页

- **收藏夹**：随便建，拖一下就换位置；「喜欢」是内置的，不能删。
- **待播**：三种——普通、**临时**（放完最后一条自己收走）、**随机临时**（按类型 / 数量 / 标签 / 作者 / 名称抽几首，可以优先挑播放次数少的）。
- **播放列表**：任何一个收藏夹或待播都能认领成当前播放列表，点「播放列表」看顺序。
- **排序**：每个收藏夹 / 待播各存各的排序（按时长 / 按首字母 / 按大小 / 按作者首字母，各自能升降序，也能是手动顺序）。**排序只管播放顺序，页面永远画存放顺序**，所以排着序也不耽误你手动拖。
- **个人主页**：自动生成一个 `听雨·XXXX` 的 id（字母表去掉了念不清的 0/O/1/I），六款生成的雨丝头像可以换。
- **个人榜单**：次数榜 / 时长榜 ×（今日 / 本周 / 本月 / 本年 / 累计）。
- 支持系统级媒体控制（Media Session）：手机下拉通知栏里那条播放台、锁屏和耳机线上的播放 / 暂停 / 上下首都能用。不想要的话在「设置 · **通知栏播放控制**」里关掉。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `空格` | 播放 / 暂停 |
| `→` / `←` | 前进 / 后退 5 秒 |
| `Shift` + `→` / `←` | 下一首 / 上一首 |
| `↑` / `↓` | 音量 ±5% |
| `M` | 静音开关 |
| `Esc` | 从最上层往下依次关掉：关于 → 确认框 → 重复检测 → 说明 → 挑选 → 编辑 → 详情 → 设置 → 唱片页 → 播放设置 → 标记面板 → 搜索下拉 → 筛选菜单 → 手机侧栏 |

播放设置和标记面板里还有：音量滑杆方向键走卡位、`Home` / `End` 到 0 / 100%，歌词框 `Ctrl`/`Cmd` + `Enter` 保存，卡片上的拖拽手柄聚焦后 `空格` 起拖、方向键挪、再 `空格` 放下。

## 数据存在哪儿

**只存在这台设备上**，在浏览器的 IndexedDB 里（库名 `tingyu`）：

- 文件**本体**真存进去了，所以刷新、重开、断网都还能播，不需要重新授权。
- 启动时会申请**持久化存储**（`navigator.storage.persist()`），降低被系统清理的概率。
- 网页版 / Windows 桌面版 / Android 手机版**各自一份数据，互不相通**，换个地方打开就是空的。没有云同步，也没有导出。

## Windows 桌面版（Electron 打包）

想以**桌面软件**的方式用（双击 exe、独立窗口、桌面/开始菜单快捷方式）：

- **两种产物**：
  - `Listra-Setup-0.1.5.exe` —— **安装包**：可选安装目录，自动创建桌面 / 开始菜单快捷方式；**卸载时会问一句要不要连保存的数据一起删**。
  - `Listra-Portable-0.1.5.exe` —— **单文件便携版**：双击直接运行，不写注册表，拷到 U 盘也能带走。
- 打包工程独立放在 **`D:\electron-tingyu`**（不随仓库走，和 `D:\Capacitor` 一样的本地工具链模式）。安装好 Node.js 后在那个目录下执行：
  ```bash
  npm install      # 首次需要，装 electron / electron-builder
  npm run dist     # 一键出两种 Windows 产物，落在 dist/
  ```
  `scripts/copy-html.js` 用绝对路径把仓库根的 `index.html` 复制进 `app/`，保证应用本体永远是仓库里那一份。
- 桌面版加载的正是网页版同一份 `index.html`，界面**完全一致**；「关于」面板里的外链会在**系统默认浏览器**里打开。

## Android 手机版（Capacitor 打包）

仓库里的 `mobile/` 是现成的 Capacitor 打包工程，工具链统一放在 `D:\Capacitor\`（jdk / android-sdk / gradle / gradle-home）：

- **一键出包**：双击 `D:\Capacitor\build-apk-listra.bat`，产物在
  `mobile/android/app/build/outputs/apk/debug/Listra-0.1.5.apk`。
  （手动的话：`mobile/` 下先 `npm install`，再 `npm run sync`，最后 `gradle -p android assembleDebug`。）
- 手机端是**另一套布局**：侧栏收成左上角滑出的抽屉，播放台重排，全屏有横屏 / 长按快进 / 防误触锁。
- APK 是 **debug 包（未签名）**，安装时手机要允许「安装未知应用」。

## 已知边界

- 「设置 · **文件位置**」在三个端上各走各的路：**桌面版**点一下就打开真正的数据文件夹（`%APPDATA%\听雨`）；**手机版**没有能打开的文件夹 —— 音视频存在应用私有目录 `/data/data/com.mingyuezai0.listra/` 里，从 Android 11 起整棵树对第三方应用关闭，系统自带的文件管理器也进不去，所以那颗按钮退一步，跳系统的「应用信息」页（在那儿能看到占了多少空间，也能清除数据）；**网页版**没有壳，按钮是灰的，点了什么也不会发生。
- **「只建索引」**的条目只记住文件在哪儿，不占空间，但原文件被删、改名或移走就找不回来了；重开软件后要重新授权同一个目录才能播。
- MP4 的内嵌封面和歌词只在 `moov` 落在文件**前 1MB** 时读得到（要读全文件代价太大，没做）。
- 部分 MP3 用 `windows-1252` 编码的中文歌词可能出乱码，这时可以自己在台词页贴一份。
- 手机端的**悬浮小窗**里那排播放 / 暂停键，是系统从播放台（Media Session）上取的。要是把「设置 · 通知栏播放控制」关了，小窗就只剩画面，得回软件里操作。
- 做不到的三件事：在线下载（绕不过 CORS）、录制、微信里播放 WebM（微信不认这个封装）。
